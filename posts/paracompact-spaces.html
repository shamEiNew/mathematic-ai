Paracompact Spaces

August 18, 2026 • Sham Topology Paracompactness Point-Set Topology

Definition: A topological space $X$ is called paracompact if each open cover for it has a locally finite open refinement for $X$.

open refinement: A collection/open cover $F_1$ is a refinement of $F_2$ if every open set in $F_1$ is contained in an open set of $F_2$.

locally finite: A collection $F \subseteq P(X)$ is locally finite if for any $x \in X$ there exists an open set $U$ with $x \in U$ such that $U$ intersects (has non-empty intersection with) only finitely many sets in $F$.

Lemma: Let $X$ be a topological space and $\mathcal{U}$ be a locally finite family. Then
(1) $\{ \bar{U}: U \in \mathcal{U}\}$ is also locally finite.
(2) $\bigcup \bar{U}$ is closed.

Proof: (1) By definition of local finiteness, for any $x \in X$ there is an open set $V$ around $x$ with $V \cap U = \emptyset$ for all but finitely many $U \in \mathcal{U}$. Now this implies $V \cap \bar{U} = \emptyset$ for all but finitely many $\bar{U}$. If a point lay in the intersection, this would mean $V \cap U \neq \emptyset$ for all $V$ containing $x$, and this would violate local finiteness of $\mathcal{U}$.

(2) Consider a point $x \in \overline{\bigcup \bar{U}}$, and by the defining property of the closure we have that $W \cap \bigcup \bar{U}$ is non-empty for all open sets $W$ containing $x$. We choose one such neighborhood $W_x$ such that it intersects finitely many $\bar{U}$, say $\bar{U_1}, \cdots , \bar{U_n}$. We assert that $x \in \bar{U_i}$ for some $i$, and if that isn't the case then there exists $W_i$ such that $W_i \cap U_i = \emptyset$, which implies $W_i \cap \bar{U_i} = \emptyset$ (using the definition of closure). Therefore, define an open set around $x$, $Z = W_x \cap W_1 \cap \cdots \cap W_n$, and this open set contains $x$, but the intersection $Z \cap \bigcup \bar{U}$ is empty: as $Z \subseteq W_x$ it can only meet finitely many $\bar{U}$, precisely the $U_i$ from above, but it is also contained in each of the $W_i$, so its intersection with these finite indices is empty, and for the other indices it is empty because of $W_x$. Hence $Z \cap \bigcup \bar{U}$ is empty, which is absurd as $x$ is a point of the closure.

Examples of paracompactness:

(1) Discrete topology on $\mathbb{R}$. As singletons are open and closed, for any open cover we can include all singletons of $\mathbb{R}$ to make a cover for the space, and each singleton meets only finitely many sets in the cover.

(2) $\mathbb{Q}$ is neither compact nor complete in the subspace topology, but it's a paracompact space. It follows from the fact that every metric space is paracompact. We don't have a canonical refinement as in the discrete case, and the construction in Stone's theorem (A. H. Stone) is genuinely involved.

Theorem: A locally compact, Lindelöf space is paracompact.

Proof: We first establish the fact $X = \bigcup_n U_n$ where each $\bar{U}_n$ is compact and $U_n \subseteq \bar{U}_n \subseteq \bar{U}_{n+1}$. Let $x \in X$; we choose $A_x$ such that $\bar{A}_x$ is compact, and this is because of the definition of local compactness. Now $\{A_x : x \in X\}$ is an open cover for $X$, and using the Lindelöf property we have a countable subcover $A_1, A_2, \cdots, A_n \cdots$. Define $U_1 = A_1$; $A_1$ is part of the original cover, so $\bar{A}_1 = \bar{U}_1$ is compact. And this countable cover also covers $\bar{A}_1$, so there exists $m_1$ such that $A_1, \cdots, A_{m_1}$ covers $\bar{U}_1$. Define $U_2 = \bigcup_{i=1}^{m_1} A_i$ and note that $U_1 \subseteq \bar{U}_1 \subseteq U_2$, and $U_2$ is a union of open sets where each $\bar{A}_i$ is compact, and therefore $\bar{U}_2$ is compact. We define $m_n > m_{n-1}$ such that

$$\bar{U}_n\subseteq\bigcup_{i=1}^{m_n}A_i:=U_{n+1}$$

and so we get a sequence satisfying the chain property. Further, $\bigcup U_n$ covers $X$ as it is built from the countable cover $A_i$. We have essentially established that $X$ is $\sigma$-locally compact and $\sigma$-compact.

Finally, using the established properties we prove paracompactness. Let $\{\mathcal{W}_{\alpha}\}$ be an arbitrary cover for the space $X$; we need to prove there exists a locally finite refinement which covers $X$. We define

$$U_0=U_{-1}=U_{-2}=\emptyset$$

and for each $n \geq 1$ and each $\alpha$

$$V_\alpha^n=(U_n-\bar{U}_{n-3})\cap W_\alpha$$

Observe that $V_\alpha^n \subseteq W_\alpha$ for all $\alpha$, and for any $x \in X$ we have $x \in U_n$ (smallest $n$) and $x \in W_\alpha$. Therefore, $\{V_\alpha^n\}$ is an open refinement of $\{\mathcal{W}_{\alpha}\}$.

The interesting part is that $\bar{U}_{n-1} - U_{n-2}$ is a compact subset of $U_n - \bar{U}_{n-3}$. To see this,

$$\bar{U}_{n-1}-U_{n-2}=\bar{U}_{n-1}\cap (X-U_{n-2})$$

which is an intersection of two closed sets and a subset of $\bar{U}_{n-1}$, which makes it a compact subset of $U_n - \bar{U}_{n-3}$. To see the subset relation, $U_n - \bar{U}_{n-3}$ sits higher because $\bar{U}_{n-1} \subseteq U_n$ and $\bar{U}_{n-3} \subseteq U_{n-2}$, and therefore the complements are contained as needed.

Now each $\bar{U}_{n-1} - U_{n-2}$ is compact and covered by $\{V_\alpha^n\}$ for a fixed $n$, and it admits a finite subcover $F_n$ for each $n$.

$$F=\bigcup F_n$$

covers $X$. To see this, for $x \in X$ we have a smallest $n$ such that $x \in \bar{U}_n$ but $x \not\in \bar{U}_{n-1}$, and so $x \in F_{n+1}$.

Finally, to see local finiteness note that for any $x \in X$

$$x \in U_n$$

it intersects finitely with $F$. Now observe that $U_n \cap (U_m - \bar{U}_{m-3}) = \emptyset$ for all $m \geq n+3$, and $U_n \subseteq \bar{U}_n \subseteq U_{m-3}$. This shows $U_n$ can only meet members with index less than $n+3$, establishing local finiteness. $F$ is our locally finite refinement of the original cover.
